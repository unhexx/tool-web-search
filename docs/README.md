# Документация tool-web-search

Клиентский поиск по локальному JSON-корпусу. Живой веб — только свой SearXNG и только когда офлайн выключен. Слушает loopback, пакет на stdlib.

| [Корпус](CORPUS.md) | Добавить документы и понять, почему две ссылки склеились в одну. |
| [Развёртывание](DEPLOY.md) | Поднять compose и не завести второй SearXNG. |

| [Цикл](LOOP.md) | `./init`, `./loop`, шлюз `:8110`, pxpipe `:8100`. |
| [Очередь](AGENT_TASKS.md) | Что уже сделано в репозитории. |
