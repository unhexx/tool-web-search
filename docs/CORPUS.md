# Корпус

Корпус — JSON-массив объектов. Кодировка файла UTF-8. Если по пути нет файла, поиск по корпусу возвращает пустой список и, при выключенном офлайне, может опереться только на SearXNG.

Путь выбирает `corpus_path()`:

1. `WEB_CORPUS`, если переменная задана.
2. `./corpus/index.json` от текущего каталога процесса, если файл существует.
3. `/app/corpus/index.json` — путь внутри образа. Compose монтирует `./corpus` туда только для чтения.

Не-массив в корне файла читается как пустой корпус.

## Поля строки

| Поле | Обязательность | Куда попадает |
| --- | --- | --- |
| `title` | нет | Хит и поиск по словам. Пустое становится `""`. |
| `url` | нет | Хит и ключ дедупа. |
| `snippet` | нет | Короткий текст хита. Именно его режет `budget_chars`. |
| `body` | нет | Участвует в счёте, в ответ не копируется. |
| `image` | нет | Если непустое, копируется в хит. При `images=true` строки без `image` пропускаются. |

Пример:

```json
[
  {
    "title": "Agentic loop template",
    "url": "https://github.com/unhexx/agentic_loop_template",
    "snippet": "Self-improving agentic loop",
    "body": "tools select compose searxng",
    "image": "https://example.invalid/loop.png"
  }
]
```

## Как считается совпадение

Запрос режется по пробелам, токены и текст приводятся к нижнему регистру. В текст строки входят `title`, `url`, `snippet`, `body`, `image`. Счёт хита — число токенов, которые входят как подстрока. Нулевой счёт отбрасывается. Сортировка по убыванию счёта, затем обрезка до `num_results` ещё до склейки с SearXNG. Повторная обрезка до того же лимита происходит после дедупа.

Пустой запрос до поиска не доходит: API отвечает 400.

## Канонический URL

Дедуп сравнивает не исходную строку, а канонический вид.

- `file:` и строки без схемы или хоста не меняются.
- Схема и хост в нижнем регистре.
- Порты `:80` для `http` и `:443` для `https` снимаются. Остальные порт сохраняют.
- Параметры `utm_source`, `utm_medium`, `utm_campaign`, `utm_term`, `utm_content`, `utm_id`, `gclid`, `fbclid`, `mc_cid`, `mc_eid` выкидываются. Остальной query сортируется.
- Хвостовой `/` у пути длиннее одного символа снимается. Корень `/` остаётся.
- Фрагмент (`#...`) снимается.

Локальный хит с тем же ключом вытесняет хит SearXNG: в склейку сначала идут локальные строки.

## Бюджет символов

`budget_chars` считает длину `json.dumps` массива хитов: UTF-8 символы Python, разделители без пробелов. До 64 проходов: самый длинный snippet короче 25 символов больше не режется, вместо этого отбрасывается последний хит. Один оставшийся snippet можно обнулить. Если после этого JSON всё ещё длиннее бюджета, ответ честно помечает `context.over_budget: true`.

Картинки поиска этот бюджет не рисует. Точные URL остаются текстом.
