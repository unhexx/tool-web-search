# Changelog

## 1.1.1

- `secret_key` SearXNG больше не хранится в git. `deploy/searxng/init-settings.sh` при первом старте пишет ключ в volume `searxng_data` и на следующих запусках его не меняет.

## 1.1.0

- `./init` ставит соседний шаблон цикла, venv и адрес шлюза pxpipe в `activate`. Дерево шаблона в git не копируется.
- `./loop` показывает роли и гоняет mock-цикл до ревьюера. `./loop --live` не стартует без шлюза `:8110` и pxpipe `:8100`.
- Выдача умеет бюджет символов, канонический URL и картинки из корпуса без сети.
- Пример `compose.env.example`. На 1.1.0 ключ SearXNG ещё лежал в settings; вынесен в 1.1.1.

## 1.0.0

- Локальный корпус и опциональный свой SearXNG. Слушает только loopback.
